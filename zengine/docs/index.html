Engine Architecture & Capabilities

Designed for absolute resilience and high-performance local AI automation

Append-Only Event Log

Sessions are stored as immutable JSONL events paired with content-addressed SHA-256 binary blobs. State reconstruction is crash-proof and reproduces exact previous context.

Deterministic Prefix Cache

Pure context builders with sorted-key serialization guarantee byte-identical renders. Each conversational turn strictly extends history at the tail, keeping remote KV cache hit rates near 100%.

Multi-Provider Streaming

First-class streaming adapters for Gemini, OpenAI-compatible (Ollama, vLLM, OpenRouter), Anthropic Messages, and custom gateways with thought-signature retention and token usage tracking.

OS-Level Concurrency & Locks

Single-writer session ownership is guarded by true operating system file locks (`owner.lock`). Process termination cleanly relinquishes claims without stale heartbeat leaks.

Strict Size & 413 Guards

Requests are sized pre-flight. When nearing body limits, aged tool attachments are pruned first, followed by intelligent compaction prompt generation, completely avoiding gateway 413 rejections.

Tri-Modal Interfaces

Headless execution, terminal Bubbletea TUI, and embedded web UI all connect to a single local control server over SSE. Closing an interface never interrupts a working agent.
